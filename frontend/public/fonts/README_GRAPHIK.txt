DOSSIER FONTS - POLICE GRAPHIK
==================================

Pour intégrer la police Graphik (Région Auvergne-Rhône-Alpes) :

1. Aller sur : https://befonts.com/graphik-font-family.html
2. Télécharger les fichiers de police Graphik
3. Placer les fichiers dans ce dossier avec les noms exacts :
   - graphik-regular.woff2 (poids normal 400)
   - graphik-medium.woff2 (poids moyen 500)  
   - graphik-bold.woff2 (poids gras 700)

Les déclarations @font-face sont déjà configurées dans main.scss

Une fois les fichiers ajoutés, redémarrez le serveur de développement
pour voir la police Graphik s'appliquer sur tout le site.
